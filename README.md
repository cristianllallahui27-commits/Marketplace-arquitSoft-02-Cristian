# Marketplace de productos para mascotas

## Integrante
llallahui gómez, cristian mier

## Descripción
Marketplace académico de productos para mascotas, donde distintos sellers publican
sus productos y los clientes pueden buscarlos, agregarlos al carrito y comprarlos.

## Caso de estudio
Se usa como referencia funcional el marketplace GoPet (https://www.gopet.pe/).
